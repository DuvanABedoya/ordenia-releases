# Ordenia — instaladores

Aquí se publican los instaladores de Ordenia para Windows. El código de la aplicación es privado.

## Instalar

1. Entre a [Releases](https://github.com/DuvanABedoya/ordenia-releases/releases/latest) y descargue `Ordenia-…-instalador.exe`.
2. Ábralo. Como el instalador no está firmado, Windows puede mostrar «Windows protegió su PC»:
   haga clic en **Más información** y luego en **Ejecutar de todas formas**.
3. Ordenia queda en el menú Inicio y en el escritorio.

## Actualizaciones

Ordenia revisa sola si hay una versión nueva. Cuando la descarga, aparece un aviso abajo a la
izquierda: «Versión … lista · Reiniciar».
